Sistema de Detección de Fraudes

Estado del Sistema Panel de Control

Este sistema fue desarrollado como parte de un proyecto de tesis para demostrar cómo se puede detectar actividad fraudulenta en transacciones bancarias mediante el uso de modelos de aprendizaje automático. A través de la simulación de transacciones en tiempo real, el sistema muestra cómo tecnologías como Kafka (para el procesamiento de eventos), MLflow (para gestionar modelos), FastAPI (para exposición de servicios), PostgreSQL (para almacenamiento) y Grafana (para visualización) trabajan de manera integrada.
